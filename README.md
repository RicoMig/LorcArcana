# LorcArcana

Jogo de Disney Lorcana para Windows. Dá para montar um deck e jogar no seu computador, sozinho ou com outra pessoa, passando o computador na troca de vez.

Projeto de fã. As cartas pertencem à Disney e à Ravensburger. Na primeira abertura o jogo baixa as cartas. Não precisa criar conta.

## Baixar

O programa está na pasta [download](https://github.com/RicoMig/LorcArcana/tree/main/download).

Clique aqui para salvar o arquivo: [LorcArcana-Windows.zip](https://github.com/RicoMig/LorcArcana/raw/main/download/LorcArcana-Windows.zip)

1. Abra o arquivo baixado.
2. Escolha **Extrair tudo**.
3. Entre na pasta e dê dois cliques em **lorcarcana.exe**.

Mantenha o `lorcarcana.exe` dentro dessa pasta, junto dos outros arquivos. É assim que o jogo abre.

Na primeira vez o Windows pode mostrar um aviso azul. Clique em **Mais informações** e depois em **Executar assim mesmo**. Deixe a internet ligada nessa abertura, para as cartas serem baixadas.

## Como jogar

1. Espere o menu mostrar que as cartas chegaram.
2. Abra **Editar deck**, monte as cartas ou toque em **Montar treino**, e salve.
3. **Praticar** joga contra o computador. **Partida local** é para duas pessoas no mesmo computador.
4. No começo, confirme a mão. Se estiver jogando com outra pessoa, passe o computador antes de mostrar a mão dela.
5. No seu turno, tinte uma carta, jogue, explore, desafie e encerre o turno. Segure o clique numa carta para ver a ficha.

Ganha quem chega a 20 de lore. A partida também termina se alguém desistir ou ficar sem cartas no deck no fim do próprio turno.

Quando uma carta pedir um efeito e o jogo não resolver sozinho, use **Resolver efeito** na mesa.
